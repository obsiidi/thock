The app

thock runs entirely on your Mac. It does not collect, store or transmit personal data.

  • Keyboard input. thock uses the macOS Input Monitoring permission to be notified of key presses. Each press is turned into a sound and, if typing stats are on, added to a counter (see below). No text, characters, window titles or clipboard contents are recorded. The optional diagnostics mode of the command-line tool (--diag) prints key names to your own terminal only when you run it yourself.
  • Motion sensor. On supported MacBooks thock reads the built-in accelerometer to estimate how hard a key was hit. The readings are used immediately and not stored.
  • Network. The only network request thock makes is an optional check for new versions: once per launch it asks api.github.com for the latest release of the thock repository. GitHub receives your IP address as with any web request; see GitHub's privacy statement. No other data is sent.
  • Typing stats. thock counts, per day, how many keys you pressed, how often each key was pressed, your active minutes, your fastest minute, clicks and scroll distance — and, on MacBooks with the motion sensor, how hard you hit. It never records characters, words or the order of keys. The numbers are stored only in ~/Library/Application Support/thock/stats.json. Turn them off or delete them in the Stats window.
  • Trackpad and mouse. Clicks and scrolling are turned into sounds and counted as described above. No pointer positions are read or stored.
  • Settings. Your preferences (chosen pack, volume, switches) are stored locally in ~/Library/Preferences/com.obsidi.thock.plist. Imported packs are stored in ~/Library/Application Support/thock/packs.
  • No account, no analytics, no telemetry, no crash reporting.
