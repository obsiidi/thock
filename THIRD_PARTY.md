# Third-party content

thock's code is MIT-licensed (see `LICENSE`). The bundled sound packs are
recordings made by other people and ship under their own terms:

| Pack folder | Name | Source | License |
|---|---|---|---|
| `packs/cherrymx-blue-abs` | CherryMX Blue – ABS keycaps | [hainguyents13/mechvibes](https://github.com/hainguyents13/mechvibes) (`src/audio`) | MIT (Mechvibes repository) |
| `packs/cherrymx-brown-abs` | CherryMX Brown – ABS keycaps | same | MIT |
| `packs/cherrymx-red-abs` | CherryMX Red – ABS keycaps | same | MIT |
| `packs/cherrymx-black-abs` | CherryMX Black – ABS keycaps | same | MIT |
| `packs/topre-purple-hybrid-pbt` | Topre Purple Hybrid – PBT keycaps | same | MIT |
| `packs/nk-cream` | NK Cream (original by Ryan) | same | MIT |
| `packs/holy-pandas` | Holy Pandas | [tplai/kbsim](https://github.com/tplai/kbsim) via Mechvibes | MIT, Copyright (c) Thomas Lai (`packs/holy-pandas/LICENSE`) |

The five single-file packs were converted from the upstream `sound.ogg` to
FLAC (lossless from the decoded Vorbis, 16-bit) so they load on every
supported macOS version; the slice tables in `config.json` are unchanged.

The pack format (`config.json` with Windows/libuiohook key codes) is the
[Mechvibes](https://mechvibes.com) format; thock reads it but is not
affiliated with Mechvibes.

`Samples/click.wav` is generated by `Tools/gen-click.swift` and carries no
third-party rights.

## Website fonts

The site in `site/` self-hosts two typefaces so that no visitor request goes
to a third party:

| File | Typeface | License |
|---|---|---|
| `site/fonts/archivo-latin.woff2` | Archivo (Omnibus-Type) | SIL OFL 1.1 — `site/fonts/OFL-Archivo.txt` |
| `site/fonts/jetbrains-mono-latin.woff2` | JetBrains Mono (JetBrains) | SIL OFL 1.1 — `site/fonts/OFL-JetBrainsMono.txt` |

If you are the author of one of these recordings and want it removed or
credited differently, open an issue.
