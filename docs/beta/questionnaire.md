# thock beta — five questions

1. Installation: did it work without help? If you got stuck, at which step
   (download / "was not opened" / Open Anyway / Input Monitoring / setup
   window / something else)?

2. Key force: type a sentence lightly, then hard. Do you hear the
   difference? (clearly / a bit / no). Did you move the soft–hard slider,
   and where did you leave it?

3. Sounds: which pack did you end up using? Any pack that sounded wrong,
   too loud, too quiet, or had a key that made no sound?

4. Daily use: is it still running? If you turned it off, why (annoying
   after a while / colleagues / music / performance / forgot it exists)?

5. Compared to Thock (free) or Haptyk ($8): would you pick thock? Why or
   why not? If you'd pay for something in thock, what would it be?
